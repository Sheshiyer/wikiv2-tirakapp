# Tirak Messaging Framework

This is the governing language reference for app copy, App Store metadata, screenshots, review notes, advertising, notifications, email, support, and public documentation.

## Master Description

Tirak is a marketplace for discovering and booking guided cultural experiences in Thailand. Travelers choose a named activity with a defined itinerary, request a date, and pay Tirak after the local guide confirms availability. Verified guide profiles, service reviews, booking-scoped logistics chat, reporting, and support help make each booking clear and accountable.

## One-Line Description

Book guided local experiences with clear itineraries in Thailand.

## Approved Headline Options

- Explore Thailand with a clear local itinerary.
- Guided food, culture, market, and city experiences.
- Choose the experience. Know the route. Meet your guide.
- Local expertise for a better-planned day in Thailand.

## Traveler Message Hierarchy

1. Start with the activity: what the traveler will do or learn.
2. State the itinerary, destination, duration, and meeting point.
3. State inclusions, exclusions, group format, and accessibility.
4. Show guide credentials and languages as trust evidence.
5. Show the total experience price and cancellation terms.
6. Explain that payment opens only after guide confirmation.
7. Describe chat as logistics for an existing booking.

## Guide Message Hierarchy

1. Create a clearly named guided activity.
2. Define the route, learning outcome, timing, and included service.
3. Publish a total experience price rather than a price for personal availability.
4. Confirm only dates on which the listed itinerary can be delivered.
5. Use booking chat for meeting and itinerary coordination.
6. Build reputation through completed-service reviews.

## Approved Vocabulary

| Use | Meaning |
| --- | --- |
| Traveler | The customer booking a travel service |
| Local guide | The accountable provider of the listed activity |
| Guided experience | The purchasable real-world service |
| Itinerary | The defined plan or route |
| Experience price | The total price of the listed service |
| Booking request | A dated request awaiting guide confirmation |
| Confirmed booking | An accepted itinerary eligible for payment |
| Meeting point | The location where the experience begins |
| Booking chat | A logistics channel tied to one booking |

## Prohibited or Retired Vocabulary

Do not use these as Tirak product claims: companion, companionship, date, dating, hangout, chemistry, vibe matching, human connection, make a friend, loneliness cure, paid company, available tonight, book this person, hourly rate, discreet service, adult, escort, direct cash to your guide, or the retired `Private` category.

The ordinary adjective “private” may appear only in a precise non-social context such as “private room” or “private group booking,” and should be replaced by “exclusive group format” where practical to avoid category confusion.

## Screen-Level Copy Contract

### Discovery

- Heading: **Guided experiences in Thailand**
- Filters: destination, activity category, date, duration, language, accessibility, group format
- Card: experience title, destination, duration, total price, rating, guide name

### Experience Detail

- Primary content: overview, itinerary, meeting point, inclusions, exclusions, group size, cancellation terms
- Supporting content: guide credentials, languages, completed-booking reviews
- CTA: **Request this experience**

### Booking Request

- Status: **Awaiting guide confirmation**
- Explanation: **You will be able to pay after the guide confirms this itinerary and date.**

### Confirmed Booking

- CTA: **Pay for this experience**
- Payment label: **PromptPay via Tirak**
- Status: **Payment pending** or **Paid**

### Booking Chat

- Helper: **Use this chat for meeting-point, timing, accessibility, dietary, language, and itinerary details.**

## Reviewer Description

Tirak is a Travel app for booking specific guided cultural activities in Thailand. Every transaction is attached to a named itinerary, date, duration, total service price, and confirmed booking. Local guide profiles provide credentials for the listed service. The app contains no dating, companionship, escort, adult, romantic matching, or social-discovery feature, and payment is never offered for a person's time or company.

## Release Copy Gate

Before each release, scan app source, locale bundles, fixtures, backend responses, App Store text, screenshot captions, review notes, notifications, email, and public wiki content. Any sentence that makes a person rather than an itinerary sound purchasable blocks release.
